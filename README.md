# 短信验证码模拟器

一个基于 Node.js 的本地短信验证码流程演示项目。用户凭一次性密钥领取虚构号码，页面自动查询并展示模拟验证码。管理端可查看密钥和号码的状态，补充库存并处理问题号码。

项目默认只监听本机，使用 `+000` 开头的演示号码和模拟验证码 `123456`，全程在本地完成。

## 快速开始

安装 Node.js 18 或更新版本，在项目根目录运行以下命令。项目只使用 Node.js 内置模块，无需安装 npm 依赖。

```bash
node server.js
```

| 页面 | 本地地址 | 演示凭证 |
| --- | --- | --- |
| 用户端 | [http://127.0.0.1:8088/](http://127.0.0.1:8088/) | `DEMO-KEY-001` 至 `DEMO-KEY-006` |
| 管理端 | [http://127.0.0.1:8088/admin.html](http://127.0.0.1:8088/admin.html) | `demo-admin` |

## 体验流程

1. 在用户端输入 `DEMO-KEY-001`，点击「获取手机号」。
2. 系统分配一个演示号码并开启 10 分钟会话。页面每 5 秒查询一次，也可以点击「刷新验证码」。
3. 页面显示 `123456` 后，可在管理端看到本次密钥和号码已标记为使用。
4. 想体验换号时，可以用另一把未使用的密钥领取号码，并在验证码出现前换号。每个会话最多换号 3 次。未完成的会话超时后，系统会在后续请求中释放其占用的密钥和号码。

管理端支持批量生成密钥、补充号码、查看问题号码记录，以及恢复符合条件的号码。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `server.js` | HTTP 服务、密钥校验、号码分配、会话状态和管理接口 |
| `user.html`、`user.js` | 用户端页面、倒计时和验证码查询 |
| `admin.html`、`admin.js` | 管理端页面和库存操作 |
| `data.json` | 密钥、号码、问题记录和会话数据 |
| `sms-endpoints.json` | 号码与查询接口的映射，随项目提供的示例为空 |
| `package.json` | 启动命令、语法检查和 Node.js 版本要求 |
| [项目思路.md](./项目思路.md) | 功能流程、状态变化和实现说明 |

运行 `npm run check` 可以检查前后端 JavaScript 文件的语法。在 Windows PowerShell 中也可以用 `npm.cmd run check`。

如需重新体验，可先停止服务，将本地 `data.json` 改名备份。重启后首次访问需要读取数据的接口时，程序会重新生成初始演示数据。
